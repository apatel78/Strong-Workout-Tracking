# Strong Workout Tracker

This repo was creaetd to track my latest and best sets for each exercise by running 
a daily sync using unofficial API endpoints from Strong App.

Since the Strong App API is not offical or published anywhere, all files besides the txt
files used to track my workout progress are hidden.

In the future, I may open the code files to the public while removing the actual endpoint, so users can find
the api endpoint on their own and recreate this.
